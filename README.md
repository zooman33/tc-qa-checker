# tc-qa-checker

> Track-changes verification for bilingual DOCX translation files

<!-- badges (CI · license · python · ruff) are added in the documentation pass -->

> **Status:** early scaffold. The full feature set and documentation land with the first release.

A command-line tool and Python library that verifies tracked changes (insertions and
deletions) were correctly carried across a bilingual translation pair — catching missed
edits, numeric divergences, and structural mismatches between a source and target DOCX.
